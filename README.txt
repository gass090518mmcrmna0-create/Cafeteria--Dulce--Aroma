# Cafetería Dulce Aroma

Proyecto escolar de una página web para una cafetería.

## Archivos
- index.html: página principal.
- estilos.css: diseño y estilos.

## Para publicarla en GitHub Pages
1. Crea un repositorio llamado `Cafeteria-Dulce-Aroma`.
2. Sube `index.html` y `estilos.css`.
3. Entra a Settings > Pages.
4. En Source selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda.
7. GitHub generará el enlace de la página.
